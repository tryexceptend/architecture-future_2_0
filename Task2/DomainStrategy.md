# Стратегия разбиения бизнеса на домены

Для реализации целей бизнеса предлагается разбить компанию на следующие домены:

1. Бизнес-домены:
   
   1. Домен "Клиника" - Работа клиник, врачей, ресепшенов, учет и сопровождение пациентов клиник;
   
   2. Домен "ИИ" - Занимается разработкой ИИ агентов, сопровождением ML-моделей;
   
   3. Домен "Финтех" - Объединяет в себе различные финансовые услуги, предоставляемые клиентам. Банк и внутренние платежи;
   
   4. Домен "Фармацефтика" - Объединяет в себе различные финансовые услуги, предоставляемые клиентам;

2. Внутренние домены:
   
   1. Домен "Платформа" - Разрабатывает политики и стандарты для доменов. Сопровождает платформу с метаданными. Занимается мониторингом системы. В начале отвечает за интеграции со сторонними системами;
   
   2. Домен "Безопасность" - Отвечает за обеспечение охраны, информационную безопасность;
   
   3. Домен "Бухгалтерия" - Занимается бухгалтерской отчетностью;
   
   4. Домен "Кадры и Склад" - Кадровый отдел. Работа с персоналом. Складской учет и операции по нему;
   
   5. Домен "Аналитика" - Работает с данными различных доменов компании. Разрабатывает стратегии развития и осуществляет аналитику дейстельности компании.

Разбиение на домены позволит командам сосредоточиться на одной бизнес модели. Домен "Платформа" разработает стандарты для обмена информации между доменами. Так же они будут ответственны за создание "витрины данных" которая организует источники данных доменов в единую платформу метаданных. Это позволит использовать ее в качестве узла интеграции новых доменов и систем.

## Бизнес-домены

1.1 Выделение домена "Клиника" выделяет бизнес связанный с обслуживанием работы клиник в подразделение. Это позволит подразделению сконцентрироваться на улучшении работы клиник.



1.2 Домен "ИИ" будет владеть уникальными знаниями в области создания различных AI-агентов, для сфер бизнеса. Они будут сконценрированы на улучшении ML-моделей, интергации агентов и их функционировании.  



1.3 Домен "Финтех" представляет собой новую отрасль развития бизнеса. Это новые знания, которые потребуют новых подходов и людей. Они будут предоставлять новые возможности для компании и клиентов.



1.4 Домен "Фармацефтика" так же является новым продуктом в компании. Следует Создать для него отдельный департамент со своей стратегией развития.

## Внутренние

2.1 Домен "Платформа" должен появиться в рамках задачи по создании "витрины данных". Задачи этого домена:

- разрабатывать стандартными API для систем;

- разрабатывать схемы данных для "витрины";

- разрабатывать интерфейсы интеграции внутренних и сторонних систем в "витрину";

- поддерживать и сопровождать работу "витрины данных".



2.2 Домен "Безопасность" отвечает за обеспечение безопасности. Это:

- охрана и охранные системы объектов компании;

- контроль соблюдения информационной безопасности;

- контроль соблюдения правовых норм в части конфедициальных данных;

- предоставление и контроль прав доступа.



2.3 Домен "Бухгалтерия" отвечает за финансовые операции компании и отчетность в контролирующие органы.



2.4 Домен "Кадры и Склад" выделен в отдельную структуру, поскольку компания представляет собой большой конгламерат клиник, компаний, банков. Требуется большой штат сотрудников для организации работ. Поэтому выделение их в отдельный домен, позволит консолидировать их опыт и предоставить услуги для других доменов.



2.5 Домен "Аналитика" - это новый домен и отрасль развития компании, которая будет заниматься развитием. Использование "витрины данных" позволит консолидировать много информации о действии компании, что предоставит возможности по анализу разных сфер. Этот департамент будет анализировать данные, предлагать стратегии развития, выявлять проблемные зоны и так далее. Уникальные знания, собранные в этом домене, будут помогать в работе остальных отраслей.
